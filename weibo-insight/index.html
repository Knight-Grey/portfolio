07

方法与局限

数据能说明什么，比数据本身更重要。这一节主动交代边界， 因为任何一份没有边界说明的舆情结论，都经不起追问。

HOW IT WAS DONE / 数据与方法

  1. 数据来源：微博热搜榜公开接口、话题搜索页、微博评论接口。全部为公开可见内容。
  2. 采集范围：热搜前 N 名话题 → 每个话题按「热门」排序取前若干条博文 → 每条博文抓取评论区分页数据。
  3. 评论覆盖率：—。微博的评论接口在若干页后会让分页游标归零， 因此这个数字是平台机制造成的上限，不是全量。
  4. 样本偏差：博文是「热门」排序下的前几条，天然偏向高互动内容；话题评论量越大，覆盖率越低。
  5. IP 属地：是评论发布时的网络出口归属地，不等于用户籍贯或常住地，只能作为粗略的地理线索。
  6. 情感判定：用情感词典 + 否定词 / 程度副词规则打分后归为正、中、负三类， 不是模型分类。规则法的好处是可解释、可复现，代价是判不出反讽和反问 （"呵呵真棒" 会被判成正面）。因此情绪那一节只看整体分布，不适合逐条引用。
  7. 时间截面：这是一次固定时点的快照，不含历史趋势与传播路径（转发链未被采集）。
